# 변수와 타입공부
## 변수
### 변수이름 작성규칙
- 영어 대소문자를 구분한다
- 첫 번쨰 글자는 문자거나 '_', '$'로 시작해야한다
- 숫자로 시작할 수 없다
- 예약어는 사용할 수 없다
- 문자 수의 제한은 없다
- 첫 문자는 영어 소문자로 시작해야한다
- 다른 단어가 붙을경우 첫 문자를 대문자로 한다

## 타입
### 기본타입
- 정수타입 : byte, short, int, long, char
- 실수타입 : float, double
- 논리타입 : boolean

### 타입변환
- 허용범위 크기순 : byte < short < int < long < float < double
